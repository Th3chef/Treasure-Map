Treasure Map

While the tactical map is open, Treasure Map marks what is still lying
around in the mission: Requisition Slips, Common, Rare and Super
Samples, Medals and Super Credits, each kind in its own color.

The Objectives option marks the side objectives you haven't discovered
yet and, with the Poor Intel modifier, the real spot of each main
objective the map only shows as an area (in the game's main objective
orange). A marker goes away once the game shows that objective on its
own map, or when the objective is done.

Every pickup gets its own marker; only pickups of the same kind lying
on the same spot (stacked, like several in one bunker) share one,
with how many it stands for next to it.

The loot ledger, at the bottom left just outside the map, lists each
enabled kind with how many are still lying around; it goes down as
things are collected, and kinds you've cleared are dimmed and checked
off. Objectives sit at the top of the ledger, above a divider, with how
many are still to be found.

Requires Bingus Shared Loader v19 or newer.

Install / update: add the zip in your mod manager (Arsenal / HD2 Mod
Manager), keep "Treasure Map (core)" on, pick the kinds you want, then
Purge and Deploy.

With CowboyBingus's Mod Options Menu (optional), the MODS tab has a
TREASURE MAP section with an opacity slider per kind.

After a game update it finds the game's addresses again by itself.
If it can't, it switches itself off and says so in its log:
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\TreasureMap.log
(test builds: ...\Logs\test\TreasureMap.log)

Reads game memory only; never writes it.
